# According to James v0.2.0

A native Unity dungeon crawler with thirty floors across three dungeons.

- James offers unnamed mystery gifts, optional finger pulls and unreliable secret passages.
- Mild mishaps cause temporary effects or small nonlethal damage.
- Chests can be trapped; secrets can land you in a shallow pit.
- Rest shrines are the only save points: floors 1, 5 and 9 of each dungeon.
- Enemies patrol, navigate around obstacles, wind up attacks, shoot and retreat.
- New pixel-like animation sheets for the hero, three bosses and regular enemies.
- Butterscotch Granny, Lunch Lady Ladle Fury and Chef Grumble have distinct attacks.
- Original chiptunes, comedic James music, a synthesized fart effect, HUD, map and Settings-only difficulty.

Extract the Windows ZIP before running AccordingToJames.exe. Keep the Data folder and DLLs alongside it. Unity editor version: 6000.3.12f1 (6.3 LTS).

Verified: campaign mechanic checks, Windows build and native runtime initialization. Audible playback needs a manual playthrough.
